# Embedded Systems Group Project

## Overview
This project is a collaboration for the Embedded Systems course. It focuses on developing embedded solutions and includes various components, including source code, reports, and project files.

## Project Structure
The project consists of the following key components:

- **Question1/**: Directory containing implementations and results related to Question 1 of the project requirements.
- **Question2/**: Directory with implementations and results for Question 2.
- **report.pdf**: A comprehensive report summarizing the findings and results of the project.
- **Source Code**: Includes the main source code file, `main.c`, as well as Keil μVision project files to aid in development and testing.

## Usage
To build and run the project, ensure you have Keil μVision installed, and follow these steps:

1. Open the project file in Keil μVision.
2. Build the project to compile the code.
3. Upload the firmware to the embedded device.
4. Run the program to see the results.
